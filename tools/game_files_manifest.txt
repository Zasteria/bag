# What to copy out of an EU5 install, and who wants it.
#
# Read by both tools/extract_game_files.py and tools/extract_game_files.ps1, so
# adding a directory here adds it to both. One path per line, relative to the
# folder that contains `in_game/`; everything after `#` is the reason, and an
# entry with no reason left can be dropped.
#
# A directory missing from an install is reported, not fatal: Paradox renames
# folders, and both scripts also sweep in_game/common/ for any file mentioning
# `monthly_towards_`, which catches the renamed ones regardless.
