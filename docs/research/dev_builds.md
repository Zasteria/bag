# Dev-сборки в дереве — что в них есть, 2026-09-12

Владелец положил в `reference/mods/` две сборки разработчиков, ещё не
вышедшие в релиз. **Всё ниже прочитано по коду; в игре не проверено ничего.**

**CMF dev не отличается от релизной ничем.** `diff -rq` между
`3692202776_community_mod_framework` и `3789103426_community_mod_framework_dev`
даёт два файла: `metadata.json` и картинку. Обе 2.4.1. **Нового API у CMF нет** —
не искать.

**Construction Manager dev 2.3.0 — большая перестройка**, около сотни новых
файлов. Семейства по префиксу: `cm_ab_*` (автострой переписан: роспись, бюджет,
ядро, своё, еда, дороги), `cm_ln_*` (Lucky Nations — автоматизация для выбранных
ИИ), `cm_fb_*` (чужие здания: стройка в локации другой державы), `cm_gov_*`
(планировщик губернаторов), `cm_proximity_finder_*` + `cm_pf_*` (поиск места
батчами по тикам), `cm_cleanup_*` (раз в год закрывает и сносит переставшие
зарабатывать), `cm_trmm_*` и `cm_town_right_map_mode_*` (режим карты «лучшая
грамота» с выдачей и панелью поиска), `cm_slice_*` (вращающееся подмножество
рынков), `cm_log_effects.txt` (свой лог по категориям с тумблером на каждую),
`cm_pop_sample_effects.txt` (прирост населения, которого в скрипте нет, —
разностью счётчиков месяц к месяцу), `cm_score_apply_*` / `cm_queue_approval_*`
(движковые числа из интерфейса — [`interface.md`](interface.md)).

**И одна вещь, которая касается вопроса «нужен ли нам CMF»:**
`main_menu/common/game_rules/cm_ln_game_rules.txt` — настройки через **правила
игры в лобби**, `has_game_rule` в скрипте, `flag = general_rule` ставит строку на
экран правил. CMF для этого не нужен вовсе; цена — выбор делается один раз при
старте партии и внутри игры не меняется.
