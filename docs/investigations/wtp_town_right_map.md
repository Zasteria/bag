# Карта «Лучшее городское право» из CM dev: перенос и расчёт

Его слово, 2026-09-13: «доставай из CM DEV карту, которая раскрашивает городские
земли в цвет городских прав… Твоя задача просто скопировать эту карту и её
расчёты. Вот как раз в расчётах этой карты я бы хотел, чтобы ты познакомился
поближе. Они будут очень кстати к нашему моду и алгоритму соответствия земли для
прав.»

Перенесена файлами, не формулой — правило из
[`../archive/wtp2_failed.md`](../archive/wtp2_failed.md). Ни одно число не
тронуто: карта нужна **эталоном**, с которым можно сверять наш счёт («если без
чёткого понимания у нас с ним будет разница — я решу, что у него правильно»).

## Расчёт, ради которого это и брали

Всё считается **один раз за загрузку**, проходом
`bag_wtp_trmm_recompute_province_definition` по каждому определению провинции, и
кладётся переменными на каждый её кусок; карта и подсказка потом только читают.
Так у него, так и здесь: «Variables stored on the province_definition itself do
not read back, so everything is staged in locals and written to every slice».

**Единица покрытия — не процент, а бонус.** `bag_wtp_trmm_rgo_unit` (scope:
локация) = 0.1 базовых плюс по 0.025 за `rgo_logistics_discovery` и
`rgo_logistics_mil_choice`: столько «Местного доступа к сырью» даёт полностью
покрытая провинция. Всё остальное меряется в этих единицах.

**Вариант способа** `_opt_<товар>_<n>` (scope: определение провинции) — доля
**всего** входа этого способа, которую провинция может дать своим РГО:

```
bag_wtp_trmm_opt_wine_1 = {
    value = 0
    if = { limit = { any_location_in_province_definition = { raw_material ?= goods:fruit } }  add = 0.823 }
    if = { limit = { any_location_in_province_definition = { raw_material ?= goods:lumber } } add = 0.112 }
}
```

Числа — доли входа в рецепте. Заметь: **достаточно одной локации в провинции**,
дающей сырьё, чтобы доля засчиталась целиком.

**Покрытие товара** — лучший вариант, затем поправка на саму локацию:

```
bag_wtp_trmm_cov_wine = {
    value = 0
    if = { limit = { province = { has_variable = ... } } province = { add = var:... } }
    # право поднимает и само это сырьё, так что на его локации РГО входит
    # в среднее как ещё один полностью покрытый поставщик
    if = { limit = { raw_material ?= goods:wine } add = 1  divide = 2 }
    add = bag_wtp_trmm_lm_wine
}
```

`_lm_<товар>` — местный модификатор вывода этого товара, делённый на
`_rgo_unit`, **минус 0.2, если право уже выдано** (иначе карта хвалила бы землю
за то, что сама же на неё положила).

**Счёт права — среднее арифметическое покрытий его связки**, без весов:

```
bag_wtp_trmm_right_textile  = (cov_cloth + cov_fine_cloth + cov_dyes) / 3
bag_wtp_trmm_right_naval    = (cov_naval_supplies + cov_tar) / 2
bag_wtp_trmm_right_tooling  =  cov_tools
```

Дальше — лучший индекс `_best_idx` на локацию (им и красится земля), `_tie_idx`
для ничьих, `_tier_*` для «какое это место в списке» и `_rightval_*` — тот же
счёт, но в деньгах (`_val_<товар>` × доля бонуса права).

## Что из этого стоит перенять нашему `_plan_right_*`

Наш счёт прав считает **по локации**. У него — **по определению провинции**, и
это правильнее: грамота даёт «Местный доступ к сырью» всей провинции, а сырьё
лежит по разным её локациям. Отсюда три отличия, каждое стоит проверки на нашей
стороне:

1. **Вход считается долями рецепта, а не «есть/нет товара».** Товар, дающий 8 %
   входа, и товар, дающий 82 %, у нас весят одинаково.
2. **Способ выбирается лучший из возможных**, а не текущий.
3. **Собственное РГО локации входит в среднее как полное покрытие** — у нас оно
   не входит вовсе.

**Ничего из этого ещё не перенесено в наш расчёт.** Карта стоит рядом как
эталон; сверка — следующая работа.

## Как это запускается у нас

`bag_wtp_trmm_recompute_all` зовётся из `bag_wtp_register` за клеймом
`bag_wtp_trmm_stamp` (`bag_wtp_trmm_data_is_current`, версия
`bag_wtp_trmm_version_value`). **Клеймо здесь обязательно**: регистрация CMF
срабатывает при каждом открытии страницы мода, а не только на загрузке, — без
клейма это был бы полный проход по карте на каждое открытие.

Вручную — кнопка «Карта городских прав → Пересчитать» на «Технической»: сырьё и
модификаторы вывода по ходу партии меняются, а проход больше не идёт.

## Что поймал чекер на этом переносе

`set_local_variable` не считался записью, а `local_var:x` попадал в ветку
`var:(\w+)` шаблона чтения — перед `var:` там нет границы слова. Девятнадцать
честно записанных локалов были названы ошибкой. Исправлено в
`tools/check_script.py`.
