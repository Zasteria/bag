# Repairs that are a search and replace.
#
# Every pair here is applied, in this order, to every key that a hard rule in
# `locscan.py` flags. A key whose value changes and comes out clean is written
# into the mod; a key that changes and is still broken makes `generate.py`
# refuse, naming it. A pair that never matches anything is reported too — a
# patch has moved the text out from under it.
#
# Prefer a rewrite over a literal wherever the repair is mechanical. A rewrite
# keeps whatever prose Paradox ships today, so it survives them editing the
# sentence; a literal freezes the sentence as it was the day it was written.
#
#   key:  <the one key this applies to; omit to apply it wherever it matches>
#   from: <text to find>
#   to:   <text to put there>
#   why:  <what is wrong, and how we know>
#
# Leading and trailing spaces are stripped from both, so a pair cannot depend on
# them. Lines starting with # are comments.

# ===========================================================================
# Brackets.
#
# `[` opens a data function and `]` closes it. One that is never closed
# swallows the rest of the line; one that closes nothing leaves the text in
# front of it printed raw, `Concept(...)` and all. Either way the engine says
# `Failed parsing localized text` and the player sees a fragment.
#
# Each of these is one key, because closing a bracket takes reading the
# sentence: the repair is not "put a `]` at the end", it is "the translator
# meant this much to be a data function".
# ===========================================================================
