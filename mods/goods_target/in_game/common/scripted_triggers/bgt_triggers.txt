# Is the log toggle on?
#
# Read carefully rather than directly. CMM keeps a setting's value in the
# country's `cmm` variable map, and asking a variable map for a key it does not
# hold is not false -- it is an error, and an error in a trigger takes the
# effect that called it with it. A setting registered with default_value = 1
# need not have been written to the map yet, so the absence has to mean "on"
# and not "off": otherwise the very first month after a new game logs nothing
# and there is no way to tell that from the mod being broken.
# Scope: country
bgt_logging_on = {
	OR = {
		NOT = { is_key_in_variable_map = { name = cmm target = flag:bgt__log_readings } }
		"variable_map(cmm|flag:bgt__log_readings)" >= 1
	}
}
