# National Destinies — Russian

Русская локализация для **National Destinies — Formables Content**
(`trin.national_destinies`; версию печатает `python3 tools/refs.py`, в прозе её
не держим): мод даёт каждой образуемой стране древо судьбы, событие образования,
свои здания, войска, ополчения и бюрократии.

## Зачем он нужен

Базовый мод поставляет одиннадцать языков, и **все они — английский текст**. Все
220 файлов в его `localization/russian/` побайтово равны файлам в `english/`,
отличается только заголовок `l_russian:`. Поэтому в русской игре мод читается
по-английски вперемешку с русским интерфейсом.

Отсюда главное отличие от `auto_build_ru`: там ключей просто не было, а здесь они
**есть**, и наш мод их **перекрывает**. Перекрытие проверено в игре и работает —
решает порядок загрузки, побеждает мод, загруженный позже. `metadata.json`
объявляет зависимость от базового мода, и в лаунчере наш должен стоять **после**
National Destinies.

### Совместимость с машинным переводом из мастерской

В Steam есть перевод этого мода гугл-переводчиком. Слои складываются:
машинный ниже, наш выше. Наши файлы называются `*_ru_generated_l_russian.yml`,
файлы того мода — как у базового (`nd_adu_l_russian.yml`), совпадений имён нет,
значит подмены файла целиком не будет и перекрытие пойдёт по ключам.
**Английского от нас не добавится нигде**: генератор физически не пишет
непереведённые ключи.

## Как это устроено

```
translations/<файл>.yml     источник правды, по одному на файл базового мода
tools/generate_ru.py        собирает игровые файлы и проверяет их
tools/scope.py              что осталось перевести и в каком порядке
tools/term.py               как игра сама называет своё понятие
priority.txt                порядок работы: Европа, затем остальной мир
GLOSSARY.md                 принятые термины и правила
english_generated_fingerprints.txt   ← пишет генератор: с какого английского
                                       переведён каждый ключ
main_menu/localization/russian/*_ru_generated_*.yml   ← пишет генератор
```

Источник правды — `translations/`. Игровые файлы **пишет генератор**, руками их
править нельзя: имя содержит `_generated_`, и следующий запуск всё перезапишет.

Файл базового мода, для которого источника ещё нет, просто не собирается. Ключ,
которого нет в источнике, в выходной файл не попадает и остаётся за базовым
модом. Поэтому перевод можно вести и по файлам, и по слоям (сначала названия,
потом описания) — и остановиться в любой момент без поломок.

## Три команды, которыми ведётся работа

**Что осталось, по приоритету:**

```
python3 mods/nd_ru/tools/scope.py --plan
    nd_ger         нужно  101   остальной прозы  112
```

`нужно` — рабочий набор страны: её названия плюс полное событие образования
(`nd_<тег>.1.*`), то есть то, что было заказано. `остальной прозы` — описания
улучшений и тексты прочих событий, они за рамками текущего заказа.

**Что переводить в конкретном файле:**

```
python3 mods/nd_ru/tools/scope.py nd_ger          # рабочий набор
python3 mods/nd_ru/tools/scope.py --full nd_ger   # вообще все ключи файла
```

Печатает `ключ<таб>английское значение` только для непереведённого. `--full`
нужен для больших систем (ситуации, бедствия), которые заказаны целиком.

**Собрать и проверить:**

```
python3 mods/nd_ru/tools/generate_ru.py
    файлов:    59 из 220   (26.8%) затронуто
    ключей:   4174 из 40790 (10.2%)
    слов:    44520 из 690376 (6.4%)
```

## Когда базовый мод обновился

Обновление трогает не только новые ключи: оно переписывает и те, что уже
переведены. Разметка при этом может и не измениться, и тогда ни одна проверка
ниже ничего не заметит — русский просто продолжит рассказывать про механику,
которой в моде больше нет. Так в 1.3.7 переписали `DNM_f_desc`, и нашёлся он
руками.

Поэтому генератор помнит, **с какого английского** переведён каждый ключ:

```
python3 mods/nd_ru/tools/generate_ru.py
    английский оригинал изменился у 2 ключей — перевод мог устареть:
      nd_dnm_country: DNM_f_desc
      nd_dnm: nd_dnm.21.a_tt
      свериться с базовым модом, поправить перевод, затем generate_ru.py --accept
```

Игровые файлы при этом всё равно пишутся (устаревший русский лучше английского),
но запуск возвращает ошибку и держит её, пока ключ не разобран, — то есть хук
начала сессии показывает `FAIL nd_ru` ровно тогда, когда это нужно. Разобрав,
запустить `generate_ru.py --accept`: он запишет новый отпечаток.

Новые ключи обновления видны обычным `scope.py --full <файл>`.

## Что генератор не пропустит

Он **отказывается писать файл**, который покажется на экране неправильно, и
называет ключ. Каждая из этих проверок появилась после реальной ошибки:

| Проверка | Что было бы без неё |
| --- | --- |
| ключа нет в базовом моде | выдуманный ключ не отрисуется никогда |
| потеряна или добавлена разметка `[...]`, `$...$`, `@icon!`, `#G`, `\n` | движок читает её, а не показывает: `ERROR:` или слипшийся текст |
| неэкранированная `"` | строка обрывается на середине |
| квадратная скобка в обычном тексте | отрисуется как `ERROR:` |
| символ не из кириллицы и не из латиницы имён | **в текст дважды просачивался китайский иероглиф** |
| английское служебное слово, которого нет в оригинале | **в русской фразе осталось `though`** |
| латиница и кириллица внутри одного слова | **`territoryов`: английское слово с русским окончанием** |
| английский оригинал ключа изменился после перевода | русский рассказывает про механику, которой больше нет |
| пустое значение | пустая строка на экране |

Проверки на иероглиф, на английское слово и на смешение алфавитов поймали
ошибки, которые сессия допустила сама и не заметила глазами. На объёме в сотни
строк такое неизбежно, поэтому проверки важнее, чем внимательность. Каждая из
них появилась после того, как ошибка уже случилась, — и это и есть способ здесь
работать: правило, выученное дорого, кладут внутрь проверяльщика, а не только в
прозу.

Латинские имена собственные (`Antemurale Christianitatis`) проходят: проверка на
английские слова смотрит только служебные слова и только те, которых нет в
английском оригинале того же ключа.

## Порядок работы над страной

1. `scope.py --plan` — взять первую строку, где `нужно` не ноль.
2. `scope.py <файл>` — получить список непереведённого.
3. Свериться с `GLOSSARY.md`; незнакомое понятие игры — через `term.py`.
4. Дописать пары в `translations/<файл>.yml` (заголовок `l_russian:`, один
   ведущий пробел, значение в прямых кавычках, файл в UTF-8 с BOM).
5. `generate_ru.py` — пока не пройдёт чисто.
6. Коммит. Одна страна — один коммит, так проще откатывать.

## Что дальше

Порядок в `priority.txt`. Осталось по нему **5 832 ключа рабочего набора
(25 тыс. слов)** — примерно одна сессия того же размера, в которую было сделано
всё перечисленное выше. Полная проза тех же стран — ещё 6 693 ключа и 214 тыс.
слов сверх того.

Весь мод целиком — **34 618 ключей, 646 тыс. слов**, около двадцати шести таких
сессий. На подписке Pro это не окупается: объём режется по приоритету, а не
берётся весь.

Дешёвые куски, которые стоит искать в первую очередь: файл, где одна формулировка
повторяется сотнями ключей, переводится шаблоном за минуты и чинит сразу все
страны. Так были сделаны `nd_event_guards` и
`nd_bureaucracy_impact_modifier_types` — 1914 ключей ценою двух десятков строк.

## Не решено

**Ключи страны лежат не только в её файле.** У Вестфалии 88 названий были в
`nd_wes`, а ещё 10 ключей — в общем файле модификаторов бюрократий. Проверять
надо поиском по всем файлам, а не по одному:

```
python3 - <<'PY'
import re, sys; sys.path.insert(0, "mods/nd_ru/tools"); import scope
en = {}
for p in scope.BASE.glob("*.yml"):
    for k, v in scope.read(p).items(): en[k] = (v, p.name)
srcs = {}
for p in (scope.MOD / "translations").glob("*.yml"): srcs.update(scope.read(p))
tag = "wes"
left = {k: v for k, v in en.items()
        if re.search(rf'(^|_|\.){tag}(_|\.|$)', k, re.I) and k not in srcs
        and re.search(r"[A-Za-z]{2}", scope.MARKUP.sub("", v[0]))}
print(len(left)); [print(f, k, "=", v[:80]) for k, (v, f) in list(left.items())[:10]]
PY
```

**`_entry`-ключи переводить не нужно.** В `nd_event_entries` они имеют вид
`nd_wes.1.entry: "$nd_wes.1.t$"` — чистая ссылка на заголовок события. Как только
переведён `.t`, запись в журнале становится русской сама.
