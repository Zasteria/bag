# Dahomey (DAH) is an event-formed tag: vanilla DAH_f carries
# `potential = { always = no  #Formed by event }` and exists only as the data
# payload for a scripted country rebrand. It therefore has no formation event
# of ours; nd_dah.1 is an advance-gated DHE.
#
# THE BUG (Workshop 2026-08-08): with no file here at all, nothing set
# nd_dah_formed at formation. The only writer was that DHE's options, which
# require an age-3 advance, so the bureaucracy grant in
# main_menu/common/auto_modifiers/99_nd_dah.txt (gated on the variable) was
# locked behind an advance for the whole early and mid game.
#
# Vanilla route: flavor_dah.txt:70 and :105 call `form_country =
# formable_country:DAH_f`. DAH also exists at game start, where the
# monthly_country_pulse bootstrap already pre-sets the markers; this covers
# the case where it is annexed and later re-formed by the flavor chain.
#
# No trigger_event_non_silently here: nd_dah.1 is a DHE with its own
# advance trigger, and calling it at formation would only fail that trigger.
# The markers are the whole point of this file.

INJECT:DAH_f = {
	form_effect = {
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_dah_formed
		}
	}
}
