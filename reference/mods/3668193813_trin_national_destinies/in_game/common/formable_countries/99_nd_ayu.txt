# Ayutthaya (AYU) is an event-formed tag: vanilla AYU_f carries
# `potential = { always = no  #Formed by event }` and exists only as the data
# payload for a scripted country rebrand. It therefore has no formation event
# of ours; nd_ayu.1 is an advance-gated DHE.
#
# THE BUG (Workshop 2026-08-08): with no file here at all, nothing set
# nd_ayu_formed at formation. The only writer was that DHE's options, which
# require an age-3 advance, so the bureaucracy grant in
# main_menu/common/auto_modifiers/99_nd_ayu.txt (gated on the variable) was
# locked behind an advance for the whole early and mid game.
#
# Vanilla route: flavor_ayu.txt:118 calls `form_country =
# formable_country:AYU_f` on ROOT, so a player holding Lavo or Ayodhya can
# reach it. form_effect runs on that call.
#
# No trigger_event_non_silently here: nd_ayu.1 is a DHE with its own
# advance trigger, and calling it at formation would only fail that trigger.
# The markers are the whole point of this file.

INJECT:AYU_f = {
	form_effect = {
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_ayu_formed
		}
	}
}
