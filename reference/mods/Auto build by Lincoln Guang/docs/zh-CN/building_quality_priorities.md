# 建筑质量默认优先级

[English](../en/building_quality_priorities.md) | 简体中文

## 结论

自动建造采用 0～10 的建筑质量基础分，供内置预设和新建自定义模板共同使用：

- `0`：没有视频评分、用户指定或可继承分数时的默认值，也是自定义模板中的硬禁用值；内置预设仍可通过自己的允许列表显式启用。
- `2–4`：低需求、低效率或只适合少量/特定地点。
- `5–7`：情境可用到稳定优秀。
- `8–9`：产业链核心或强力地点建筑。
- `10`：跨局势优先级最高的基础保障建筑。

每点优先级折算为 `+50` 排序分，因此完整范围是 `0–500`。在当前普通建筑功能类别内部，
这足以打破同类建筑之间的市场价格代理排序，却低于食物危机的 `+6000～12000`、建筑材料
短缺的 `+3000–5000` 和上游断供的 `+3200`，所以类别内部顺序是「生存和瓶颈 > 建筑质量
> 市场价格代理」。建筑质量不能越过玩家设定的「自动建造顺序」，也不能越过食物紧急优先。

## 视频依据与映射原则

视频校准种子的评分思路来自 Bilibili UP 主 [瘦扁扁](https://space.bilibili.com/456154809)
的 EU5 内容启发。

分析了仓库相对目录 `source/` 中的四份字幕：建筑物上、中、下三期，以及一份综合种田攻略。
三期建筑评价决定建筑质量，总攻略用于校正产业链：

- 羊毛 → 布料 → 高级布料是稳定强链：羊毛上游为 7，布料链统一为 8，高级布料链统一为 9。
- 木材 → 煤 → 铁 → 工具会随时代增强，但早期受铁供给约束：对应建筑至少为 6，核心木材、
  炼铁和工具节点为 8–9。
- 木材/布料 → 纸张 → 书籍有长期价值，纸张本身价格偏低：纸张升级链统一为 7，书籍/印刷
  升级链统一为 6。
- 铁、金等稀缺原产地点不应为了城市化随意牺牲；木材可由伐木厂补充。
- 工具通常有广泛需求和出口空间；玻璃、火器、火炮等需求量依次更窄。

字幕存在语音识别误差，因此按游戏定义和升级关系校正名称。下表中的依据类型：

- `直评`：视频直接评价该建筑或明确对应功能。
- `链推`：该建筑通过原版 `obsolete` 关系继承前置建筑分数；多前置合流取最高值。
- `未校准`：视频没有足够信息且没有可继承的前置建筑，严格设为 0。
- `用户设定`：显式用户覆盖，优先于视频分和升级继承。

## 实现位置

- `policies/automation_rules.json` 的 `building_priorities` 保存范围、默认值、倍率和覆盖值。
- `policies/video_building_priorities.json` 只保存视频直评分和显式用户覆盖。
- `src/eu5autobuild/catalog_builder.py` 收录玩家可管理建筑，并按原版 `obsolete` 链生成完整数值。
- `src/eu5autobuild/rules.py` 校验所有数值位于 0～10。
- `src/eu5autobuild/generator.py` 将覆盖值写入新自定义模板，为预设加入同一基础分，并把复制的预设生成为独立玩家模板。
- `src/eu5autobuild/engine.py` 镜像相同排序语义：自定义模板的 0 分禁用候选，内置预设的显式允许列表则可覆盖全局 0。
