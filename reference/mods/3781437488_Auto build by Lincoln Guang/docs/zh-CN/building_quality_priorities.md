# 推荐建筑优先级

[English](../en/building_quality_priorities.md) | 简体中文

## 优先级生效机制

每种建筑均设有 0～10 的推荐优先级。风味模板与新建推荐模板会默认采用这些数值；空白模板则默认所有建筑均为 0，由玩家自行规划：

- `0`：完全不自动建造。风味模板可根据其专属定位特例启用个别 0 分建筑。
- `2–4`：需求量少、生产效率偏低或仅适用于极少数特定地点。
- `5–7`：视局势可用，或在对应产业链中表现稳健优良。
- `8–9`：产业链核心支柱或高价值的强力增产建筑。
- `10`：跨局势最高优先级的国计民生基础设施。

在**供需规划**模式下，每点优先级增加 50 点规划分。该分值可有效区分用途相近的同类建筑，但低于食物危机、建材短缺及关键原料断供的高额加分。因此整体调度始终遵循「生存需求与产业链瓶颈优先，其次才是建筑质量与市场价格」的原则。建筑优先级无法越过玩家设定的「自动建造顺序」。「规划候选数」（3～30）决定每个地点和普通建造类型保留多少个高分项目作为失败回退，并且仅在该模式下显示和生效。

在**预测利润择优**模式下，规划分首先在每个地点与当前普通建造类型中按「利润候选数」（3～30）预筛选候选项目，随后读取游戏预测月利润；利润相近时，每点建筑优先级约提供 1% 的相对排序加成（10 级最多约 10%）。当利润差距明显时，预测利润更高的项目依然优先开工。「利润候选数」仅在该模式下显示并生效。

## 评分参考与继承规则

推荐优先级参考了 Bilibili UP 主 [瘦扁扁](https://space.bilibili.com/456154809) 的 EU5 建筑评测与种田攻略，并结合游戏内的产业链闭环与升级体系整理而成。

参考资料包括建筑物评测（上/中/下三期）及一份综合种田指南。单体评价用于确立基础优先级，综合指南用于校准产业链关系：

- 羊毛 → 布料 → 高级布料是稳定强链：羊毛上游定为 7，布料链统一为 8，高级布料链统一为 9。
- 木材 → 煤炭 → 铁 → 工具随时代发展愈发重要，但早期受铁矿供给约束：对应建筑至少为 6，核心木材、炼铁和工具节点为 8–9。
- 木材/布料 → 纸张 → 书籍具有长期价值，虽然纸张单价偏低：纸张升级链统一为 7，书籍/印刷升级链统一为 6。
- 铁、金等稀缺原产地点不应为盲目城市化而随意牺牲；木材缺口可由伐木工场补充。
- 工具通常有广泛的内需和出口空间；玻璃、火器、火炮等需求量则依次收窄。

针对视频字幕中的语音识别误差，已对照原版定义与升级关系修正了建筑名称。下表中的依据类型说明：

- `直评`：视频直接评测了该建筑或明确分析了其对应功能。
- `链推`：根据原版升级关系继承前置建筑分数；若有多个前置建筑则取最高值。
- `未校准`：参考资料中未提及且无前置升级建筑，默认设为 0。
- `用户设定`：经人工综合调整设定，优先于视频直评分与升级继承分。

## 开发者说明

目录共检查 465 个建筑定义，收录 317 个玩家可管理建筑；排除了事件专用、阶层所有、永不
满足国家条件，以及只用于表示升级关系的定义。收录建筑中，31 个采用视频直评、8 个经过
人工调整、66 个按升级链继承、212 个暂无评分依据；最终 63 个建筑非 0，254 个为 0。

- `policies/automation_rules.json` 的 `building_priorities` 保存范围、默认值、倍率和覆盖值。
- `policies/video_building_priorities.json` 只保存视频直评分和显式用户覆盖。
- `src/eu5autobuild/catalog_builder.py` 收录玩家可管理建筑，并按原版 `obsolete` 链生成完整数值。
- `src/eu5autobuild/rules.py` 校验所有数值位于 0～10。
- `src/eu5autobuild/generator.py` 将覆盖值写入推荐模板，把空白模板初始化为 0，为预设加入同一基础分，并把复制的预设生成为独立玩家模板。编辑器支持 0.1/0.5/1.0 三档点击步进，并可清零当前就业阶层与时代筛选交集中的可见建筑。
- `src/eu5autobuild/engine.py` 镜像相同排序语义：自定义模板的 0 分禁用候选，风味模板的显式允许列表则可覆盖全局 0。
