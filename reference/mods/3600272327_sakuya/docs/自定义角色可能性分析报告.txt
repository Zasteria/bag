Europa Universalis V 自定义角色可能性分析报告
================================================
分析日期: 2026-01-08
游戏版本: 基于游戏文件分析 + 社区资源研究
参考资料: Paradox Wiki, GitHub io_pdx_mesh, Steam社区指南, Paradox论坛


一、角色可自定义的内容
========================

1. 基础属性
   - 姓名 (first_name, last_name)
   - 王朝 (dynasty)
   - 称号/绰号 (nickname)
   - 出生日期 (birth_date)
   - 出生地点 (birth_location)
   - 性别 (female = yes/no)
   - 文化 (culture)
   - 宗教 (religion)

2. 能力属性
   - 行政能力 (adm): 0-100，可设固定值或范围如 { 80 100 }
   - 外交能力 (dip): 0-100
   - 军事能力 (mil): 0-100

3. 职业/角色类型
   - 特征类别 (trait_category): ruler/general/admiral/artist/explorer/child/religious_figure
   - 艺术家类型 (artist): architect/writer 等
   - 艺术家技能 (artist_skill): 0.0-1.0
   - 庄园归属 (estate)

4. 性格特征 (traits)
   - 统治者特征: just, righteous, cruel, tolerant, kind_hearted 等
   - 将军特征、海军上将特征、艺术家特征等

5. 外观/DNA (需要script参数引用persistent_dna)
   - 详见下方DNA系统说明


二、角色形象: 3D建模系统
========================

EU5采用完整的3D人物渲染系统，不支持2D图片替代。
这与CK3、Vic3使用相同的Clausewitz/Jomini引擎技术。

形象系统组成:
- 头部模型 (male_head_entity / female_head_entity)
- 身体模型 (male_body_entity / female_body_entity)
- 儿童/青少年/婴儿模型 (boy_body_entity, girl_body_entity, infant_body_entity)
- 配饰系统 (头发、胡须、服装、头饰、项饰等)
- 贴花系统 (眉毛、皮肤细节等)

纹理规格 (Paradox专用格式):
+------------+----------------------------------------------------------+
| 纹理类型   | 通道说明                                                 |
+------------+----------------------------------------------------------+
| Diffuse    | RGB = 颜色, Alpha = 透明度                               |
| Normal     | R = 标准红, G = 标准红, B = 纯黑, A = 标准绿             |
|            | (注意: Paradox法线贴图格式与标准不同!)                   |
| Specular/  | R = 主色, G = 次色/金属放大器, B = 金属度, A = 粗糙度    |
| Properties |                                                          |
+------------+----------------------------------------------------------+

文件格式: DDS (DirectDraw Surface)


三、自定义3D模型的可能性
========================

理论上可行，但难度较高。

【核心工具: io_pdx_mesh】
GitHub: https://github.com/ross-g/io_pdx_mesh
用途: 导入/导出Clausewitz引擎游戏的mesh和动画文件

软件要求:
- Blender 3.64+ (推荐，免费且用户友好)
  - Blender 4.2+: 通过 Edit > Preferences > Get Extensions > Install from Disk 安装
  - Blender 3.64-4.1: 通过 Edit > Preferences > Add-ons > Install 安装
- Maya 2018+ (可选，动画功能更强)

Blendshape支持状态:
- CK3: 支持 (已验证)
- Imperator: Rome: 支持 (已验证)
- EU5: 未正式验证 (引擎相同，理论兼容)
- Victoria 3: 未正式验证

模型格式:
- .mesh: Paradox私有的3D网格格式
- .asset: 资源定义文件（文本格式，定义mesh、动画、混合形状等）
- .anim: 动画文件

创建自定义模型流程:
1. 在Blender中建模
2. 安装io_pdx_mesh插件
3. 按照游戏骨骼结构设置模型
4. 手动划分UV缝合线 (不要使用自动展开，会导致导出失败!)
5. 烘焙纹理 (推荐使用Ez Baker + Handplane引擎)
6. 导出为.mesh格式

推荐Blender插件:
- io_pdx_mesh (必需): Paradox mesh导入导出
- Ez Baker + Handplane: 纹理烘焙
- Principled Material Layers: 材质层管理
- Weight Flow / Weight Control: 权重绘制
- LoopTools: 网格编辑辅助

配饰添加相对容易:
- 在 gfx/models/portraits/attachments/ 下添加新配饰
- 在 common/genes/ 相关文件中注册新配饰
- 配饰分类: clothes, headwear, hair_styles, beards, neckware 等

关键骨骼节点:
- Head_B: 头部主节点
- Neck_B: 颈部节点
- Camera: 相机目标点
- head_root: 头部根节点
- bn_neck_base: 颈部基础节点

重要提示:
- Blender和Maya使用不同的坐标轴系统，io_pdx_mesh会自动补偿
- 绑定骨骼时需选择mesh和根关节(层级最高的关节)
- 绑定到根骨骼的顶点在动画中永远不会正确移动
- 自动蒙皮后必须手动修正权重


四、摄像机自定义
================

完全可以自定义! 摄像机定义在:
  main_menu/gfx/portraits/cameras/portrait_cameras.txt

摄像机参数详解:
+-------------------+--------------------------------------------------+
| 参数              | 说明                                             |
+-------------------+--------------------------------------------------+
| position          | 圆柱坐标 cylindrical{ 半径 高度 角度 }           |
|                   | 例: cylindrical{ 210 30 10 }                     |
| look_at           | 观察点偏移 { 左右 上下 前后 }                    |
|                   | 例: { 0 3 0 }                                    |
| look_at_node      | 目标骨骼节点 (Head_B, Neck_B, Camera)            |
| fov               | 视场角度 (度)，例: 10, 20, 30                    |
| camera_near_far   | 近/远裁剪平面 { 近 远 }，例: { 10 300 }          |
+-------------------+--------------------------------------------------+

现有摄像机类型及参数:
- camera_head:        cylindrical{ 210 30 10 }, fov=10, look_at Head_B
- camera_head_close:  cylindrical{ 175 15 10 }, fov=10
- camera_shoulders:   cylindrical{ 190 0 0 }, fov=20
- camera_torso:       cylindrical{ 240 -10 0 }, fov=20
- camera_body:        cylindrical{ 140 10 0 }, fov=20
- portrait_editor:    cylindrical{ 260 0 26 }, fov=10

自定义方法:
创建新摄像机定义或在mod中覆盖现有定义。


五、模型所需参数
================

1. 基础模型参数 (.asset文件):
   pdxmesh = {
       name = "模型名_mesh"
       file = "模型名.mesh"

       animation = { id = "动画ID" type = "路径/动画.anim" }
       additive_animation = { id = "附加动画ID" type = "路径/动画.anim" }
       blend_shape = { id = "形状ID" type = "路径/形状.mesh" data = "normal|tangent" }

       meshsettings = {
           name = "形状名"
           index = 0
           texture_diffuse = "漫反射.dds"
           texture_normal = "法线.dds"
           texture_specular = "属性.dds"
           shader = "portrait_skin_face"
           shader_file = "gfx/FX/jomini/portrait.shader"
       }
   }

2. 实体参数 (entity定义):
   entity = {
       name = "实体名_entity"
       pdxmesh = "模型名_mesh"

       default_state = "none"
       state = { name = "pose_01" animation = "动画ID" chance = 10 looping = yes }

       attribute = { name = "属性名" additive_animation = "动画ID" default = 0.5 }
       attribute = { name = "形状名" blend_shape = "形状ID" }
   }

3. DNA基因数值范围:
   - 所有基因值范围: 0-255 (存储在DNA字符串中)
   - 显示时映射到: -0.5 到 0.5 或 0.0 到 1.0
   - 左侧数值 = 显性基因
   - 右侧数值 = 隐性基因

4. 面部变形属性 (通过DNA控制):
   头部: head_height, head_width, head_size, head_face_forward
   下巴: chin_height, chin_length, chin_size, chin_def, chin_dimple
   颧骨: cheek_def, cheek_fat, cheek_forward, cheek_height, cheek_width
   眼睛: eye_angle, eye_forward, eye_height, eye_size, eye_spacing, eye_open
         eye_lower_lid_def, eye_upper_lid_shape, eye_upper_lid_size, eye_socket
   前额: forehead_angle, forehead_height, forehead_roundness
         forehead_brow_angle, forehead_brow_curve, forehead_brow_forward, forehead_brow_height
   下颚: jaw_angle, jaw_def, jaw_forward, jaw_height, jaw_width
   嘴巴: mouth_corner_height, mouth_forward, mouth_height, mouth_width
         mouth_lip_def, mouth_lower_lip_pad, mouth_lower_lip_size
         mouth_upper_lip_shape, mouth_upper_lip_size
         mouth_philtrum_def, mouth_philtrum_shape, mouth_philtrum_width
   鼻子: nose_forward, nose_height, nose_length, nose_width
         nose_nostril_height, nose_nostril_width
         nose_ridge_angle, nose_ridge_shape, nose_ridge_def
         nose_root_def, nose_tip_angle, nose_tip_def, nose_tip_forward, nose_tip_size
   颈部: neck_def, neck_length, neck_width
   颅骨: skull_depth, skull_height, skull_width
   耳朵: ear_angle, ear_out, ear_size

5. 颜色参数:
   - hair_color: 头发颜色 { 显性色相 显性值 隐性色相 隐性值 }
   - skin_color: 肤色
   - eye_color: 眼睛颜色


六、人物模型的定义方式
======================

游戏使用DNA/基因系统定义人物外观:

1. 基因定义文件 (common/genes/):
   - 00_genes_color.txt: 颜色基因 (头发、皮肤、眼睛)
   - 01_genes_morph.txt: 形态基因 (面部特征变形)
   - 02-07_genes_accessories_*.txt: 配饰基因
   - 08_genes_special_visual_traits.txt: 特殊视觉特征
   - 09_genes_special_expressions.txt: 表情

2. 民族模板 (common/ethnicities/):
   定义不同民族的默认外观参数范围
   示例:
   ethnicity_template = {
       skin_color = {
           10 = {
               0.25 0.2   # 左上角 (x y)
               0.75 0.5   # 右下角 (x y)
           }
       }
       expressions_mouth = {
           40 = { name = no_expression range = { 0.0 1.0 } }
           10 = { name = smile_01 range = { 0.0 1.0 } }
       }
   }

3. 持久化DNA (common/persistent_dna/custom_characters.txt):
   存储预定义角色的完整外观数据

DNA格式详解:
   角色名 = {
       priority = 1                      # 优先级
       tags = { 标签名 }                 # 用于script引用
       portrait_info = {
           genes = {
               # 颜色基因: { 显性色相 显性明度 隐性色相 隐性明度 }
               hair_color={ 62 59 203 6 }
               skin_color={ 56 30 56 30 }
               eye_color={ 178 67 178 67 }

               # 形态基因: { "模板名" 数值 "模板名" 数值 }
               # 左=显性, 右=隐性, 数值0-255
               gene_chin_def={ "template_1" 211 "template_1" 132 }
               gene_nose_width={ "template_1" 255 "template_1" 187 }

               # 配饰基因
               clothes={ "no_clothes" 0 "no_clothes" 0 }
               hair_styles={ "no_hair" 0 "no_hair" 0 }
               beards={ "no_beard" 0 "no_beard" 0 }

               # 表情基因
               expressions_mouth={ "smile_03" 137 "no_expression" 128 }
               expressions_eyes={ "no_expression" 128 "no_expression" 128 }
           }
       }
   }


七、指定样貌角色的实现
======================

历史人物和特定角色使用以下方式实现:

1. 不是单独建模! 使用既有基础模型+DNA参数生成。

2. 实现流程:
   a. 在 persistent_dna/custom_characters.txt 中定义角色DNA
   b. 给DNA条目设置tags
   c. 在事件中使用 create_character 时引用script参数

代码示例 (来自flavor_SWE.txt):
   create_character = {
       first_name = name_absalon
       dynasty = dynasty:oxenstierna_dynasty
       adm = { 90 98 }
       dip = { 90 98 }
       mil = { 90 98 }
       birth_date = 1583.6.16
       birth_location = location:enkoping
       culture = culture:swedish
       script = swe_axel_oxenstierna    <-- 引用persistent_dna中的定义
       save_scope_as = swe_axel_oxenstierna
   }

对应DNA定义 (custom_characters.txt):
   swe_axel_oxenstierna = {
       priority = 1
       tags = { swe_axel_oxenstierna }
       portrait_info = {
           genes = { ... 完整的基因数据 ... }
       }
   }

3. CK3的DNA编辑经验 (适用于理解系统):
   - 可以使用游戏内的portrait editor复制/粘贴DNA字符串
   - DNA字符串可以在存档文件中找到
   - 社区工具: https://kyusoo.github.io/CK3_Utility/DnaConverter
   - 注意: 过度使用滑块可能导致游戏崩溃


八、通过事件让自定义角色出现
============================

完全可行! 具体方法:

1. 创建角色的事件效果:
   create_character = {
       # 基本属性
       first_name = 名字
       last_name = 姓氏
       dynasty = dynasty:王朝名

       # 能力值
       adm = { 最小值 最大值 }  # 或固定值
       dip = { 最小值 最大值 }
       mil = { 最小值 最大值 }

       # 背景信息
       birth_date = 年.月.日
       birth_location = location:地点
       culture = culture:文化
       religion = religion:宗教
       female = yes/no

       # 外观 (引用persistent_dna)
       script = dna定义名称

       # 角色类型
       trait_category = ruler/general/admiral/artist
       estate = estate_type:庄园类型

       # 其他选项
       create_in_limbo = yes  # 先创建但不加入朝廷
       save_scope_as = 作用域名  # 保存引用
   }

2. 将角色设为领导人/大臣:

   方法A - 通过character_interactions:
   - appoint_as_heir: 指定为继承人
   - make_regent_ruler: 摄政成为统治者
   - grant_cabinet_right: 授予内阁权利
   - promote_to_head_of_cabinet: 提升为内阁首脑

   方法B - 通过事件效果:
   - set_character_as_the_great: 设为伟人
   - 以及其他脚本效果

3. 艺术家示例 (hire_artist.txt):
   create_character = {
       trait_category = artist
       artist = architect
       artist_skill = 0.85
       save_scope_as = new_character
   }


九、其他重要信息
================

1. 光照和环境:
   肖像渲染有完整光照系统，定义在:
   main_menu/gfx/portraits/environments/portrait_environments.txt

   光源类型:
   - spot_light: 聚光灯
   - point_light: 点光源
   - directional_light: 方向光

   光源参数:
   - color = hsv{ 色相 饱和度 明度 }
   - position = cylindrical{ 半径 高度 角度 }
   - look_at = { x y z }
   - radius, falloff (衰减)
   - outer_cone_angle, inner_cone_angle (聚光灯)

2. 年龄系统:
   模型支持动态衰老，通过age_preset曲线控制:
   age_preset_1 = {
       mode = add/multiply
       curve = {
           { 年龄比例 效果强度 }
           { 0.0 0.0 }
           { 0.32 0.0 }
           { 0.7 1.0 }
       }
   }

3. 表情系统:
   - expressions_mouth: 嘴部表情 (smile, displeased, open, pout)
   - expressions_eyes: 眼睛表情 (squint)
   - expressions_brow: 眉毛表情 (frown_angry, frown_neutral, frown_worry)
   - expressions_forehead: 前额表情 (eyebrow_raise)

4. MOD兼容性建议:
   黄金法则: 永远不要直接编辑游戏核心文件!

   - 自定义DNA: 在mod的common/persistent_dna/下创建新文件
   - 新配饰: 在mod的gfx/models/portraits/attachments/下添加
   - 新摄像机: 在mod的gfx/portraits/cameras/下覆盖或添加
   - 始终使用独立的mod文件夹覆盖或扩展基础文件

5. 工具和资源:
   必备工具:
   - io_pdx_mesh: https://github.com/ross-g/io_pdx_mesh
     (Blender 3.64+ / Maya 2018+)
   - Blender: https://www.blender.org/ (免费)

   纹理工具:
   - GIMP + DDS插件
   - Photoshop + NVIDIA Texture Tools
   - Paint.NET + DDS插件

   社区资源:
   - EU5 Mod Coop Discord
   - Paradox论坛 EU5 User Mods版块
   - CK3 Community Flavor Pack (已移植到EU5)

6. 限制:
   - 无法使用2D图片代替3D模型
   - .mesh格式无官方文档
   - io_pdx_mesh的blendshape支持仅限CK3和Imperator (EU5理论兼容但未验证)
   - 新骨骼动画需要符合游戏骨架结构

十一、总结
==========

EU5的角色自定义系统非常强大:

可以做到:
  [是] 创建具有指定属性的角色
  [是] 通过DNA系统定义精确外观 (70+面部参数)
  [是] 添加新服装/配饰 (使用io_pdx_mesh)
  [是] 自定义摄像机角度和光照
  [是] 通过事件将角色设为领导人/大臣/艺术家
  [是] 修改光照和渲染环境

有难度但可能:
  [难] 创建全新3D头部/身体模型 (需io_pdx_mesh + 骨骼适配)
  [难] 添加新骨骼动画 (需遵循游戏骨架结构)
  [难] Blendshape自定义 (EU5支持未完全验证)

无法做到:
  [否] 用2D图片替代3D模型 (引擎限制)
  [否] 突破基础模型的变形限制 (需替换基础mesh)
