[English] How to use the 'nul' file cleaner
========================================================================
Step 1: Configure the scan path
1. Right-click the "kill_nul.ps1" file and select "Edit" (or Open with Notepad).
2. Find the line: "C:\Users\Siermayde"
3. Change it to YOUR own folder path (e.g., "C:\Users\YourName").
4. Save and close the file.

Step 2: Run the script
1. Press [Win + X] on your keyboard and select "Windows PowerShell" (or Terminal).
2. Type the following command (do not press Enter yet):
   powershell -ExecutionPolicy Bypass -File 
   (Note: There is a space at the end)
3. Drag and drop the "kill_nul.ps1" file into the PowerShell window.
   (This automatically fills in the correct file path, no matter where you saved it).
4. Press [Enter] to start cleaning.

[Русский] Инструкция по удалению файлов 'nul'
------------------------------------------------------------------------
Шаг 1: Настройка пути сканирования
1. Щелкните правой кнопкой мыши по файлу "kill_nul.ps1" и выберите «Изменить» (или откройте в Блокноте).
2. Найдите строку: "C:\Users\Siermayde"
3. Замените её на путь к вашей папке (например: "C:\Users\ВашеИмя").
4. Сохраните и закройте файл.

Шаг 2: Запуск скрипта
1. Нажмите [Win + X] на клавиатуре и выберите «Windows PowerShell» (или Терминал).
2. Введите следующую команду (не нажимайте Enter сразу):
   powershell -ExecutionPolicy Bypass -File 
   (Примечание: в конце должен быть пробел)
3. Перетащите файл "kill_nul.ps1" в окно PowerShell.
   (Это автоматически подставит правильный путь к файлу, где бы он ни находился).
4. Нажмите [Enter] для начала очистки.
