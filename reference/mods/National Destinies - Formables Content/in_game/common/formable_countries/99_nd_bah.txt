# The Bahmani Sultanate: promoted from an event-payload record to a real
# formable (2026-08-14, Workshop request).
#
# THE PROBLEM. Vanilla BAH_f carries `potential = { always = no  #Formed by
# event }`, no geography and no fraction: it is the data payload (tag, name,
# adjective, flag, colour) that a scripted `form_country` needs, not a
# country anyone can choose. Its one caller is flavor_DLH.txt:154, where the
# Fall of Delhi builds a brand new country with create_country_from_location
# and rebrands it. That country is always AI. So no player could ever be
# Bahmani, while this mod had written 36 heritage advances, four
# bureaucracies, a building set and five DHEs for the tag. A subscriber
# asked for exactly this: play a Deccan sultanate, restore the Bahmani
# state, then contest the inheritance of Delhi from the south.
#
# PGR is the precedent, promoted 2026-08-08 for the same reason and in the
# same shape, and the vanilla route survives it: scripted `form_country`
# runs form_effect regardless of `potential`, which is how vanilla forms JAP
# out of the Sengoku situation while JAP_f is also `always = no`.
#
# COLLISION WITH THE FALL OF DELHI. flavor_dlh.2 is fire_only_once, needs
# `is_situation_active = situation:fall_of_delhi`, and only fires on DLH
# between 1340 and 1370 while Delhi still holds five or more Deccan
# provinces. `NOT = { country_exists = c:BAH }` in potential stops the
# reverse case (forming a tag that is already on the map). The remaining
# window, where a player holds Gulbarga and Bidar this early while Delhi
# still holds the Deccan proper, is narrow, and the worst case is that the
# scripted rebrand finds its tag taken and Delhi's breakaway keeps a
# generated identity instead. The mod does not overwrite vanilla DHEs to
# close it.
#
# LEVEL 2, vanilla's own tier, kept deliberately. It puts BAH one rung under
# DEC_f (Deccan, level 3, marathi/kannada/telugu language plus Sunni), which
# is the correct order in both directions: the Bahmani state came first
# (1347) and the Deccan sultanates are what it broke into (1490-1527), so
# restoring Bahmani and then proclaiming the Deccan is the ladder, not a
# detour. A player forming BAH keeps every route DEC already offered.
#
# WHY THESE PROVINCES. The five tarafs of the sultanate as Firishta lists
# them, plus the coast they traded through:
#   kalyana_karnakassala   Gulbarga and Bidar, the two capitals, with
#                          Kalyani and Manyakheta, the Chalukya and
#                          Rashtrakuta seats the sultanate inherited
#   raichur_doab           the Doab, the ground Bahmani and Vijayanagara
#                          fought over for the entire period
#   upper/lower_marathwada Daulatabad, where the Deccan revolt against
#                          Tughluq began, and the southern marches
#   lower_vidarbha         the taraf of Berar
#   golconda/warangal/     the taraf of Telingana, taken 1425
#     sirpur_province
#   malvana                Dabhol, the port the Persian horse trade and the
#                          Afaqi immigration both came through
# Vijayanagara's own heartland is deliberately excluded: Kampili holds
# Vijayanagar itself and belongs to VJN, not here. 91 locations, 89 of them
# ownable land, so the fraction is close to honest.
#
# 0.6 = 55 locations. More than any single successor sultanate ever held
# (each took one taraf in 1490) and less than the whole empire, which is the
# definition of restoring the state rather than inheriting a piece of it.
#
# capital_required = yes is the rootedness gate. Without it any Sunni power
# that conquered south (Gujarat, Malwa, later the Mughals) could rename
# itself Bahmani off a distant throne. With it, the seat has to be in the
# Deccan, which is the one thing every claimant to this name had in common.
REPLACE:BAH_f = {

	level = 2
	required_locations_fraction = 0.6
	rule = historical

	capital_required = yes

	potential = {
		# Sunni, matching DEC_f directly above it in the ladder. The
		# sultanate's Afaqi party leaned Shia and Bijapur and Golconda
		# went Shia after the break-up, but the Bahmani state itself was
		# Sunni and the faction quarrel is content, not a gate.
		religion = religion:sunni

		# Never two Bahmanis. If the Fall of Delhi already put one on the
		# map, the button is not offered.
		NOT = { country_exists = c:BAH }

		# Bahmani is a secession FROM Delhi. Hasan Gangu was a Tughluq
		# amir who revolted; Delhi reconquering the Deccan and calling
		# itself Bahmani inverts the whole country.
		NOT = { has_or_had_tag = DLH }
	}

	allow = {
		# Both capitals. Gulbarga was Ahsanabad and the seat from 1347;
		# Ahmad Shah I moved the court to Bidar in 1425 and it stayed
		# there to the end. Holding one without the other is a taraf, not
		# the sultanate.
		owns = location:gulbarga
		owns = location:bidar
	}

	name = BAH
	flag = BAH
	adjective = BAH_ADJ
	tag = BAH
	color = map_bahmanis

	provinces = {
		kalyana_karnakassala
		raichur_doab
		upper_marathwada
		lower_marathwada
		lower_vidarbha
		golconda_province
		warangal_province
		sirpur_province
		malvana
	}

	form_effect = {
		# Formation markers live HERE, not only in the event's options.
		# The vanilla route forms this country by script and the popup may
		# never be answered, which is what left every advance and the
		# bureaucracy grant unreachable before 2026-08-08.
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_bah_formed
		}
		# The Fall of Delhi grants the created country kingdom rank
		# outright (flavor_DLH.txt:150). A player who earns the same state
		# gets the same standing.
		if = {
			limit = { country_rank_level < 3 }
			set_country_rank_effect = { rank = country_rank:rank_kingdom }
		}
		trigger_event_non_silently = nd_bah.10
		add_stability = stability_mild_bonus
	}
}
