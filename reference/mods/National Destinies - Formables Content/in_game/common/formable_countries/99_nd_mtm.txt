# Mataram (MTM) is an event-formed tag: vanilla MTM_f carries
# `potential = { always = no  #Formed by event }` and exists only as the data
# payload for a scripted country rebrand. It therefore has no formation event
# of ours; nd_mtm.1 is an advance-gated DHE.
#
# THE BUG (Workshop 2026-08-08): with no file here at all, nothing set
# nd_mtm_formed at formation. The only writer was that DHE's options, which
# require an age-3 advance, so the bureaucracy grant in
# main_menu/common/auto_modifiers/99_nd_mtm.txt (gated on the variable) was
# locked behind an advance for the whole early and mid game.
#
# Vanilla route: decline_of_majapahit.txt:618 calls `form_country =
# formable_country:MTM_f` on ROOT, so a Sunni Majapahit player reaches it.
# form_effect runs on that call.
#
# No trigger_event_non_silently here: nd_mtm.1 is a DHE with its own
# advance trigger, and calling it at formation would only fail that trigger.
# The markers are the whole point of this file.

INJECT:MTM_f = {
	form_effect = {
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_mtm_formed
		}
	}
}
