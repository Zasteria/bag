# Malacca (MLC) is an event-formed tag: vanilla MLC_f carries
# `potential = { always = no  #Formed by event }` and exists only as the data
# payload for a scripted country rebrand. It therefore has no formation event
# of ours; nd_mlc.1 is an advance-gated DHE.
#
# THE BUG (Workshop 2026-08-08): with no file here at all, nothing set
# nd_mlc_formed at formation. The only writer was that DHE's options, which
# require an age-3 advance, so the bureaucracy grant in
# main_menu/common/auto_modifiers/99_nd_mlc.txt (gated on the variable) was
# locked behind an advance for the whole early and mid game.
#
# MLC IS THE EXCEPTION: nothing in the game calls `form_country =
# formable_country:MLC_f` at all. flavor_maj.txt:1493 builds Malacca with
# create_country_from_location + `define_unique_country_tag = MLC`, which
# never touches this block, so this form_effect does not run today. It is
# here so the tag is covered if that ever changes; what actually repairs MLC
# is the four-yearly marker sweep in 99_nd_on_actions.txt.
#
# No trigger_event_non_silently here: nd_mlc.1 is a DHE with its own
# advance trigger, and calling it at formation would only fail that trigger.
# The markers are the whole point of this file.

INJECT:MLC_f = {
	form_effect = {
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_mlc_formed
		}
	}
}
