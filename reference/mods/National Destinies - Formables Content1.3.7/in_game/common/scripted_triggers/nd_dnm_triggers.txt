# ==========================================================================
# DANUBIAN MONARCHY: shared triggers for the Reich question.
#
# Three tests that every Reich-facing piece of the Monarchy (formation
# event, Sanction weld, the two Emperor-facing interactions, the monthly
# pulse) used to spell out inline, each slightly differently. One
# definition each so they cannot drift.
# ==========================================================================

# Evaluated in a constituent crown's scope: does this crown answer to
# $REALM$ (the Monarchy)? A subject at any depth, or its personal-union
# junior. A union is an international organization in EU5, not a subject
# relation (`is_subject_or_below_of` is false for a junior), so the junior
# case needs its own test; the vanilla idiom is
# country_interactions/take_over_seniority.txt. Parametrised because the
# callers differ in what `root` is: events and form_effect pass
# `REALM = root`, the shared effects pass the scope they saved, since
# `root` inside a country interaction's effect is not documented.
nd_dnm_crown_answers_to = {
	OR = {
		is_subject_or_below_of = $REALM$
		AND = {
			in_union_with = $REALM$
			union ?= {
				country_is_senior_partner = { country = $REALM$ }
			}
		}
	}
}

# The Monarchy chose to remain within the Reich and is still a member.
# Both halves matter: the variable records the choice, the membership test
# catches a departure by any road the mod does not own (the vanilla leave
# button, a peace term, the Swiss policy), which the monthly pulse then
# turns into the break consequences (nd_dnm.54).
nd_dnm_is_in_reich = {
	has_variable = nd_dnm_in_reich
	is_member_of_international_organization = international_organization:hre
}

# Can the forming crown remain within (or enter) the Reich at all? A
# sitting member always can. A non-member (the Hungarian origin, or a
# Bohemia that had already left) needs the Empire's own join rule:
# hre.txt:338 can_join_trigger wants the Emperor's religion and adjacency
# or imperial land, which `country_can_join_international_organization`
# evaluates for us. A Hussite Hungary cannot enter a Catholic Reich, and
# the option is simply not offered.
nd_dnm_can_stay_in_reich = {
	exists = international_organization:hre
	OR = {
		is_member_of_international_organization = international_organization:hre
		country_can_join_international_organization = international_organization:hre
	}
}
