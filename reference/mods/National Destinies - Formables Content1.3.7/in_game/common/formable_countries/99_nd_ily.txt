# Illyria (Illyricum): National Destinies new formable.
#
# THE PERIOD ILLYRIA, NOT THE FAMOUS ONE. The Illyria most people know is out
# of scope: Napoleon's Illyrian Provinces are 1809 and the Illyrian Movement is
# 1830s Croatian romantic nationalism, at the very end of the game window. The
# Illyrian identity that lives through the whole of 1337 to 1836 is different
# and older: a learned, humanist and ecclesiastical self designation of the
# CATHOLIC SLAVS OF THE EASTERN ADRIATIC. Croatian and Dalmatian writers called
# their language Illyrian and themselves Illyrici. Vinko Pribojevic of Hvar
# delivered his oration on the origin of the Slavs in 1525 (printed Venice
# 1532); Mauro Orbini of Ragusa published Il regno degli Slavi in 1601; Bishop
# Peter Cedolini wrote of a common Illyrian tongue in 1592. Rome made the label
# institutional: the church and confraternity of San Girolamo degli Illirici
# (papal grant 1453, rebuilt under Sixtus V, bull Sapientiam Sanctorum 1589)
# and the Illyrian College at Loreto (Gregory XIII, 1580), which trained
# Catholic clergy for the Slavic lands under Ottoman rule.
#
# WHERE IT STOPS. Habsburg chanceries later used Gens Illyrica too (Josephine
# charters 1706, Charles VI 1713 and 1715), but that category covered the
# ORTHODOX SERB settlers of southern Hungary under the Leopoldine privileges of
# 1690, which is a different nation and is already served by SER. This formable
# is built on the Catholic strand only, so it stops where the Catholic Slavic
# world stops: Serbia, Zeta and Bulgaria are not part of it. That is the whole
# difference between this and a proto Yugoslav unifier, and it is deliberate.
#
# LEVEL 3, NOT 2. `level` is a reachability gate, not a prestige rating
# ("Players can only form countries of higher level", formable_countries
# readme, and equal is not enough). Croatia sits at level 2 through vanilla
# CRO_f, so at level 2 the one country this formable exists for could never
# press the button. This is exactly the complaint that produced the request:
# Workshop user YIGGITY reported that Dalmatia (DAL_f, level 1) is not formable
# by Croatia. Level 3 keeps every intended origin: Croatia (level 2), a formed
# Dalmatia (level 1), and Ragusa, Split and the other Dalmatian communes (no
# formable of their own, so level 0). TAB and HEN each needed the same fix.
#
# RELATION TO DAL. Dalmatia (DAL, level 1) is the maritime city state: the
# communal statutes, Adriatic trade, Dubrovnik. Illyria is its continuation
# inland, the same Catholic Slavic world consolidated as a crown, anchored on
# Split (the archbishopric that claimed primacy over Dalmatia and Croatia, and
# the humanist seat of Marko Marulic) and Zagreb (the ban's inland seat).
# Territorial overlap with DAL and CRO is expected and fine.
ILY_f = {

	level = 3
	required_locations_fraction = 0.6
	rule = plausible

	potential = {
		# The two cultures DAL_f already pairs, which is the point: this is
		# the same population one tier further on. Croatian is the CRO and
		# inland culture, Dalmatian is Ragusa, Split and the island communes.
		OR = {
			culture = culture:croatian
			culture = culture:dalmatian
		}
		# Catholic by identity, not by convenience. The whole Illyrian claim
		# in this period is Roman: San Girolamo, Loreto, and the Slavonic
		# liturgy in Glagolitic letters that Innocent IV allowed the bishop of
		# Senj in 1248. It is also the clean line against the Orthodox
		# Habsburg use of the same word.
		religion = religion:catholic
	}

	allow = {
		# Coast and interior, one city each. Split is Venetian at the start
		# with a Croatian core on it, Zagreb is the Slavonian capital. Taking
		# both is precisely the act of consolidation the country represents,
		# and neither duplicates DAL_f (Dubrovnik) or CRO_f (Zagreb alone).
		owns = location:split
		owns = location:zagreb
	}

	name = ILY
	flag = ILY
	adjective = ILY_ADJ
	tag = ILY
	color = map_ILY

	areas = {
		croatia_area
		slavonia_area
		bosnia_area
	}

	form_effect = {

		# Formation markers live HERE, not only in the event's options.

		# A country can be formed by script (vanilla forms JAP from the

		# sengoku situation), and then the popup may never be answered,

		# leaving every advance gated on this variable unreachable.

		hidden_effect = {

			set_variable = nd_formed

			set_variable = nd_ily_formed

		}
		if = {
			limit = { country_rank_level < 3 }
			set_country_rank_effect = { rank = country_rank:rank_kingdom }
		}
		trigger_event_non_silently = nd_ily.1
		add_stability = stability_mild_bonus
	}
}
