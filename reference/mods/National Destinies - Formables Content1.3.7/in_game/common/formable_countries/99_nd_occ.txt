# Occitania (OCC): National Destinies form_effect injection
#
# Vanilla defines OCC_f (level 3, rule plausible, required_locations_fraction
# 0.75, potential gated on occitan_dialect or gascon_dialect) with an EMPTY
# form_effect, so we INJECT rather than REPLACE. We add only the formation
# event hook, the state markers and the historically justified one-time
# effects. Territory, potential and allow are vanilla's and are untouched.
#
# Rank: the counts of Toulouse, the counts of Provence and the viscounts of
# Bearn were never crowned, but a single polity holding Provence, Languedoc,
# Gascony, Auvergne and the Limousin is the Carolingian regnum of Aquitaine
# in all but name, and Gaston Febus already claimed at Orthez in 1347 that he
# held Bearn "from God and from no man in the world". Kingdom, not empire:
# nothing in the Midi's history supports an imperial claim, and the mod
# reserves empire rank for polities that actually asserted one.
INJECT:OCC_f = {
	form_effect = {
		# State markers live here, not only in the event options. A content
		# layer must never depend on a popup being delivered, and country
		# variables die with the country so a re-formed OCC re-arms cleanly.
		hidden_effect = {
			set_variable = nd_formed
			set_variable = nd_occ_formed
		}

		if = {
			limit = { country_rank_level < 3 }
			set_country_rank_effect = { rank = country_rank:rank_kingdom }
		}

		trigger_event_non_silently = nd_occ.1
		add_stability = stability_mild_bonus
	}
}
